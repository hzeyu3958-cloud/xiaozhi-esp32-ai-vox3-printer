# MY-638 打印调试工具

该目录用于在电脑端把图片转换成 ESC/POS 位图、预览二值化效果、通过串口直接测试 MY-628/MY-638，并生成可嵌入 ESP32 固件的小票数据。

## 安装

需要 Python 3.10 或以上版本。

```bash
python -m pip install -r requirements.txt
```

启动图形界面：

```bash
python printer_gui.py
```

命令行说明见 [README_printer_tool.md](README_printer_tool.md)。厂商 ESC/POS 指令的 Markdown 转写见 [MinerU_markdown_MY-628_638规格书.md](MinerU_markdown_MY-628_638规格书.md)。

## 当前推荐参数

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 型号 | MY-638 | 80mm 版本 |
| 宽度 | 576 dots | 有效打印宽度 72mm |
| 波特率 | 9600 | 8N1、无流控，稳定但大图慢 |
| 后端 | raw | 直接生成 ESC/POS，兼容性最好 |
| 图片指令 | `GS v 0` | 水平光栅位图 |
| 抖动 | none/sierra | 线稿用 none，灰度图用 sierra |
| 阈值 | 170-180 | 数值越低黑色越多 |
| 浓度 | `1B 37 08 8C 14` | 当前固件使用的平衡参数 |

## 图片处理流程

1. 图片缩放到不超过 576 dots。
2. 转为灰度并调整对比度、Gamma 和阈值。
3. 使用 none、ordered 或 sierra 二值化。
4. 生成 `GS v 0` 光栅字节流。
5. 按条带或小块写入串口，最后走纸。

固件中的内置模板位于 `main/boards/ai-vox3/printer_*.escpos`，对应预览图包括：

- `lucky_ticket_template.png`
- `country_card_egypt_bw.png`
- `wealth_ticket_bw.png`

## 波特率与速度

串口一字节通常需要 10 个传输位。9600 波特率的有效速度约为 960 byte/s，所以 100KB 小票仅发送数据就需要约 107 秒；136KB 小票约需要 142 秒。

改为 115200 可以显著提速，但必须同时修改：

1. 使用厂商配置工具把打印机本体改为 115200。
2. 把 `main/boards/ai-vox3/config.h` 中的 `PRINTER_UART_BAUD_RATE` 改为 115200。
3. 重新编译并烧录 ESP32。

只修改一端会导致无输出或乱码。ESP32 烧录命令中的 `-b` 只控制电脑与 ESP32 的下载速度，不会改变打印机波特率。

## 浓度说明

MY-638 使用 `ESC 7 n1 n2 n3` 设置最多加热点数、加热时间和加热间隔：

- `n1` 越大，同时加热点越多，速度可能更快，但峰值电流更大。
- `n2` 越大，颜色越黑，同时更慢、更容易过热。
- `n3` 越大，间隔越长，通常更清晰，但打印更慢。

不要把三个参数直接全部设为 `FF`。这会造成过流、过热、竖纹、掉点，甚至缩短打印头寿命。当前固件采用 `08 8C 14`，模板文件中已有浓度命令时会由发送层统一替换。

## 常见故障

### 完全不打印

检查打印机是否上电、GND 是否共地、TX/RX 是否交叉，以及两端是否都为 9600。发送 `1B 40 12 54` 可触发打印机自检页。

### 整体偏浅

先确认热敏纸正反面、纸张质量和电源是否达到 5-9V/1.5A，再调整阈值或加热时间。浓度设置不能修复损坏的打印头。

### 一半清晰、一半不清晰

如果固定在纸张同一侧，通常是盖板压力不均、胶辊/打印头脏污、打印头排线松动或打印头损坏。若内部自检页也相同，可以排除图片、串口和固件问题。

### 固定竖纹或缺列

先断电清洁打印头与胶辊，并重新压紧盖板两侧。若故障位置始终不变，需要检查打印头 FPC 排线或更换打印头。

### 打印大图中途乱码

减小单次写入块、确认供电稳定，并检查是否误用了不匹配的波特率。不要在一条 `GS v 0` 数据中间插入状态查询指令。
